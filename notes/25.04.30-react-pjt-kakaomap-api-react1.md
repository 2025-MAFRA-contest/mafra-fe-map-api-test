## API 키 발급 받고 개발 세팅하기

1. **[카카오 디벨로퍼스](https://developers.kakao.com/)** 접속  
2. **로그인 후, 내 애플리케이션 등록**
    - 오른쪽 상단 `내 애플리케이션` 클릭 → `애플리케이션 추가`
    - **앱 이름**은 원하는 대로 작성 (예: `KakaoMapReactApp`)
    - **사업자명**은 개인 개발자는 아무 이름이나 입력 가능
3. **앱 생성 후 플랫폼 등록**
    - 좌측 메뉴에서 `플랫폼 > 웹` 클릭
    - `사이트 도메인`에 개발용 주소 추가  
        예:
        ```
        http://localhost:5173
        ```
        배포 시에는 실제 도메인도 함께 등록해야 함
4. **JavaScript 키 복사**
    - 좌측 `앱 키` 메뉴 클릭
	- `.env.local` 파일 생성
		- 루트 디렉토리에 `.env.local` 파일을 만들고 아래와 같이 작성:
	    ```env
	    VITE_KAKAO_API_KEY=여기에_복사한_자바스크립트_키_입력
	    ```
		- **주의**: 키 이름은 반드시 `VITE_`로 시작해야 Vite에서 인식 가능
	- SDK를 동적으로 로드하는 유틸 함수 작성
	- `src/lib/loadKakaoMap.ts` 혹은 `src/utils/loadKakaoMap.ts` 등으로 아래 유틸리티 함수 생성:
	```ts
	export const loadKakaoMap = (): Promise<void> => {
	  return new Promise((resolve, reject) => {
	    if (document.getElementById('kakao-map-sdk')) {
	      resolve();
	      return;
	    }

	    const script = document.createElement('script');
	    script.id = 'kakao-map-sdk';
	    script.src = `//dapi.kakao.com/v2/maps/sdk.js?appkey=${import.meta.env.VITE_KAKAO_API_KEY}&autoload=false`;
	    script.onload = () => {
	      window.kakao.maps.load(() => {
	        resolve();
	      });
	    };
	    script.onerror = reject;
	    document.head.appendChild(script);
	  });
	};
	```
5. (선택) **도메인 미등록 시 오류 방지**
    - Kakao Map API는 등록된 도메인에서만 작동함
    - 오류: `Uncaught Error: Insecure origin` 발생 시 도메인 등록 여부 확인
