## 처리할 일

---

#### **1. 마커 등록**

- **할 일**
    - `kakao.maps.MarkerOptions[]` 배열로 마커 정보 정의
    - 각 항목을 순회하며 `new kakao.maps.Marker()` 생성
    - `marker.setMap(map)` 으로 지도에 부착
- **개념**
    - `position`은 `kakao.maps.LatLng` 인스턴스를 요구함
    - `title`은 마우스 오버 시 툴팁처럼 표시됨
    - 마커는 지도 객체가 생성된 이후에 부착해야 함

---

#### **2. 마커 클릭 이벤트 처리**

- **할 일**
    - `kakao.maps.event.addListener()` 로 마커 클릭 이벤트 등록
    - 클릭 시 `getPosition()`으로 좌표 추출 후 처리
- **개념**
    - 카카오맵 전용 이벤트 시스템을 사용 (`addListener`)
    - 콜백 내에서 `marker.getPosition()` 사용 시 마커 인스턴스를 클로저로 유지해야 함

---

## 결과물

```ts
const createMarker = () => {
  if (!map.current) return;

  const markers = [
    {
      title: '서울시청',
      position: new kakao.maps.LatLng(37.566826, 126.978656),
    },
    {
      title: '남산타워',
      position: new kakao.maps.LatLng(37.5511694, 126.9882266),
    },
    {
      title: '경복궁',
      position: new kakao.maps.LatLng(37.579617, 126.977041),
    },
  ];

  markers.forEach((thisOption: kakao.maps.MarkerOptions) => {
    const thisMarker = new kakao.maps.Marker(thisOption);
    thisMarker.setMap(map.current);

    kakao.maps.event.addListener(thisMarker, 'click', () => {
      const latlng = thisMarker.getPosition();
      alert(`현재 클릭한 위치: 위도 ${latlng.getLat()}, 경도 ${latlng.getLng()}`);
    });
  });
};
```
