#### **1. 컨트롤러 등록**

- **할 일**
    - 추가할 컨트롤러 객체 생성
    - ``addControler()`` 메서드 이용해서 컨트롤러 추가
- **개념**
    - `addControler()`은 `kakao.maps.MapTypeController` 혹은  `kakao.maps.ZoomController` 인스턴스를 요구함
    - `addControler()`는 ``kakao.maps.ControlPosition`` 객체의 상수도 요구함

---

## 결과물

```ts
const createController = () => {

if (!map.current) return;

const mapTypeControl = new kakao.maps.MapTypeControl();

const zoomControl = new kakao.maps.ZoomControl();

  

map.current.addControl(mapTypeControl, kakao.maps.ControlPosition.TOPRIGHT);

map.current.addControl(zoomControl, kakao.maps.ControlPosition.RIGHT);

}
```
