## 처리할 일

#### **1. 지도 객체를 담을 요소와 객체를 ref로 선언**

- **할 일**
    - `useRef()`로 div 요소와 지도 객체를 관리
- **개념**
    - `ref`는 React 렌더링에 영향을 주지 않고 값을 유지함
    - 지도 객체는 DOM에 직접 연결되므로 state가 아닌 `ref` 사용이 적합함
 
---

#### **2. 지도 생성 함수 작성 (`loadMap`)**

- **할 일**
    - `mapContainer.current`에서 div 요소를 얻고
    - `new kakao.maps.Map(...)`으로 지도 인스턴스를 생성
- **개념**
    - `center`, `level` 등 옵션으로 초기 위치와 줌 수준 설정
    - 생성된 지도 인스턴스는 `ref`에 저장하여 외부에서 접근 가능하게 함

---

#### **3. Kakao Maps API 스크립트 동적 삽입 (`loadScript`)**

- **할 일**
    - `<script>` 태그를 동적으로 생성하여 API 로드
    - 중복 삽입 방지를 위해 기존 태그 유무 확인
- **개념**
    - `autoload=false` 옵션을 사용했기 때문에 `kakao.maps.load()` 필수
    - script가 중복되면 `load()`가 호출되지 않아 API 사용 불가 오류 발생

---

#### **4. useEffect를 통해 초기 진입 제어**

- **할 일**
    - 마운트 시점에 API가 로드된 상태인지 확인 후 `loadMap()` 또는 `loadScript()` 실행
- **개념**
    - `useEffect`는 마운트 직후 한 번만 실행되므로 지도 재생성을 방지할 수 있음
    - `deps=[]`로 리렌더링 시 재호출 방지

---

#### **5. JSX로 지도 표시용 div 설정**

- **할 일**
    - `ref` 연결된 `div`에 적절한 width/height 스타일 지정
- **개념**
    - Kakao Map은 div 내부에 canvas 등을 렌더링하므로 최소 높이 필요
    - `ref`가 연결되지 않으면 지도 객체 생성 실패

---

## 결과물

``` ts
import { useEffect, useRef } from 'react';

  

export default function Map() {

/*
ref로 관리하는 이유

1. 컴포넌트가 살아있는 동안 값을 유지하고
2. 값 변경으로 인해 리랜더링이 되지 않게 하기 위해
	- 값 변경을 유도할거라면 useState 훅으로 상태를 만들면 되는데 지금은 목적에 안 맞음
*/

// 지도 객체가 담기는 div 태그 관련 ref

const mapContainer = useRef<HTMLDivElement>(null);

// 지도 객체가 담기는 ref

const map = useRef<kakao.maps.Map | null>(null);

// 지도 생성

const loadMap = () => {

const container = mapContainer.current;

const options = {

center: new window.kakao.maps.LatLng(37.566826, 126.978656),

level: 3,

};

if (!container) {

console.error('container is null');

return;

}

map.current = new window.kakao.maps.Map(container, options);

createMarker();

};

  

// 카카오맵 스크립트 동적 로딩

const loadScript = () => {

// scrpit 태그의 property 가 "dapi.kakao.com" 을 포함하면 가져오기

if (document.querySelector('script[src*="dapi.kakao.com"]')) {

// 이미 스크립트가 있으면 바로 loadMap

if (window.kakao && window.kakao.maps) {

loadMap();

} else {

window.kakao.maps.load(() => loadMap());

}

return;

}

const script = document.createElement('script');

script.src =

`//dapi.kakao.com/v2/maps/sdk.js?appkey=${import.meta.env.VITE_KAKAO_MAP_API_KEY}&autoload=false`;

script.onload = () => {

window.kakao.maps.load(() => {

loadMap();

});

};

document.head.appendChild(script);

};

// 리액트에서 컴포넌트 생명주기 관리는 모두 useEffect를 통해 진행
// 지금 같이 설정하면 컴포넌트 마운팅을 확인함

useEffect(() => {

if (window.kakao && window.kakao.maps) {

loadMap();

} else {

loadScript();

}

}, []);

  

return (

<div>

<h2>카카오맵</h2>

<div id="map" ref={mapContainer} style={styles.map}></div>

</div>

);

}

const styles = {

map: {

width: '100%',

height: '500px'

}

}
```
